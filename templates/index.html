Welcome to the Zero-Trust Sandbox

This interface demonstrates a secure RAG pipeline that protects confidential data from reaching 3rd-party LLM providers.

  1. Ingest: Paste confidential employee records or healthcare data below. The system encrypts Names, Emails, SSNs, and PANs into secure tokens (e.g. <<PERSON_01>>).
  2. Verify: Watch the Processing Log to witness the aggressive real-time interception and dataset sanitization.
  3. Query: Ask a targeted question like "What is John's email?". The LLM receives only masked tokens and the server safely unmasks the resulting answer locally.
